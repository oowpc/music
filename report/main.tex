\begin{abstract}
传统音频声学特征（如 MFCC、Chroma 等）依赖短时傅里叶变换（STFT）窗口参数，对伴奏混响与音色叠加极为敏感。本文提出一种基于符号音乐信息检索（Symbolic MIR）的曲风分析范式：将 MIDI 旋律抽象为三维欧氏空间 $\mathbb{R}^3$ 中的离散点集曲线 $\{(t_i, m_i, v_i)\}$，引入 Modified Hausdorff 距离（MHD）作为核心相似性度量，辅以标准 Hausdorff、离散 Fr\'{e}chet 及 DTW 三种对照度量，构建 $N \times N$ 距离矩阵并通过 Classical MDS 降维与层次聚类实现无监督曲风区分。

实验基于五类曲风共 116 首高纯度样本，MHD 取得类间/类内分离比 2.23$\times$、KNN 留一法准确率 79.31\%（随机基线 20\%）。横向对比中 MHD 以 82.0\% 显著优于其余三种方法。MDS 可视化表明 Folk 与 Pop 形成紧密自然聚类（召回率 100\%），Classical 与 Jazz 存在部分重叠，Rock 严重嵌入 Pop 区域。系统实现了从 MP3/WAV 音频到 MIDI 符号序列的端到端转录与分析流程，工程架构与运行说明见附带文档 \texttt{system-guide.md}。

\end{abstract}

\section{问题重述}
%═══════════════════════════════════════════════════════════════

传统曲风分类依赖 MFCC、Chroma 等音频声学特征，这些特征高度依赖短时傅里叶变换（STFT）窗口参数，对伴奏混响、音色叠加及分轨噪声极为敏感——同一首歌曲的录音室版本与现场版本在 MFCC 空间中的欧氏距离可能远超不同曲风歌曲之间的距离。这一根本性缺陷导致基于声学特征的曲风分类系统的可复现性长期处于瓶颈。

本研究转向\textbf{符号音乐信息检索（Symbolic MIR）}路径：直接以 MIDI 等符号化乐谱为分析对象，将旋律抽象为几何空间中的点集曲线，从而彻底剥离伴奏、混响与音色等声学噪声。本文聚焦以下四个核心问题：

\begin{enumerate}[label=(\arabic*),leftmargin=2em]
    \item 基于三维旋律线的 Hausdorff 距离能否有效区分不同曲风？
    \item 时间、音高、力度三个维度中，哪个对曲风区分的贡献最大？
    \item 标准 Hausdorff、Modified Hausdorff、DTW，哪种更适合 MIDI 旋律相似性度量？
    \item MDS 降维可视化中，不同曲风是否形成自然聚类？
\end{enumerate}

\section{问题分析}
%═══════════════════════════════════════════════════════════════

\subsection{问题一的分析}

判断三维旋律线的 Hausdorff 距离能否区分曲风，本质上是一个\textbf{特征空间判别力评估}问题。若不同曲风的旋律在三维几何空间中形成可分离的聚类结构，则基于 Hausdorff 距离的相似性度量应能有效捕获这种结构。评估手段包括：KNN 留一法分类准确率是否显著高于随机基线（20\%）；类间距离与类内距离的分离比（separation ratio）是否大于 1.5；混淆矩阵中各类别召回率是否均衡。

\subsection{问题二的分析}

维度贡献的差异源自各维度在不同曲风之间的内在分布差异，而非量纲或范围差异——Min-Max 归一化已将三维映射至等权的 $[0,1]^3$ 单位立方体。通过分析混淆矩阵中各类别的混淆方向（如 Classical 误分为 Jazz 可推断音高维度的重叠）、类内距离的紧凑性（如 Folk 类内仅 0.024 可推断三个维度均具有高信噪比），以及 Rock 与 Pop 的类间距离极小（0.115），可以判定各维度的相对贡献。

\subsection{问题三的分析}

四种距离度量在数学结构上存在本质差异：标准 Hausdorff 取 $\max\min$（$L_\infty$ 范数），对离群点极度敏感；Modified Hausdorff 取 $\mathrm{mean}$-$\min$（$L_1$ 平均意义），通过均值聚合获得统计稳定性；DTW 通过非线性时间对齐保留点序信息；离散 Fr\'{e}chet 严格保持点序约束。最适合的度量应在保证几何合理性的前提下，对 MIDI 旋律中常见的装饰音、力度波动等局部扰动具有足够的鲁棒性，同时维持类间距离的最大化。

\subsection{问题四的分析}

MDS 将高维距离关系投影至二维平面，若同曲风样本在投影空间中聚为一簇、异曲风样本彼此分离，则说明三维几何特征本身包含足够的判别信息。聚类质量可从三个层面评估：类内距离（簇的紧致性）、类间距离（簇的分离性）以及 KNN 召回率（分类边界清晰度）。

\section{模型假设}
%═══════════════════════════════════════════════════════════════

\begin{enumerate}[label=(\arabic*),leftmargin=2em]
    \item \textbf{旋律可分解性假设}：一首乐曲的旋律线可由其音符序列唯一确定，忽略和弦内低音声部对主旋律的掩蔽效应。
    \item \textbf{同音区可比假设}：所有 MIDI 文件的音高与力度均限定在 $0 \sim 127$ 的标准范围内，归一化后映射至单位立方体 $[0,1]^3$ 中可以消除绝对调性与力度差异。
    \item \textbf{时间尺度可分离假设}：Min-Max 归一化将各曲线时间轴独立压缩至 $[0,1]$，不同乐曲的时值差异不影响几何相似性度量。
    \item \textbf{点集近似假设}：将连续旋律曲线离散化为有限点集（64 点均匀重采样），在保留核心几何形态的前提下降低计算复杂度。
    \item \textbf{标签可信度假定}：数据集中曲风标签由人工标注，视为真实类别的可靠近似。
\end{enumerate}

\section{模型的建立与求解}
%═══════════════════════════════════════════════════════════════

\subsection{三维旋律几何空间映射模型}

将每首乐曲抽象为一组有序采样点构成的三维空间曲线。对第 $i$ 个音符事件，定义其在 $\mathbb{R}^3$ 中的坐标向量为：
\begin{equation}
    p_i = (t_i,\; m_i,\; v_i) \in \mathbb{R}^3
    \label{eq:point}
\end{equation}
其中 $t_i$ 为音符起始时间（由 music21 的 \texttt{getOffsetInHierarchy} 获取四分音符偏移量后乘以 $60/\text{BPM}$ 转换为绝对秒数），$m_i$ 为 MIDI 音高编号（$0 \sim 127$），$v_i$ 为 MIDI 力度（$0 \sim 127$）。第 $i$ 首乐曲的点集曲线记为 $C_i = \{p_1^{(i)}, \ldots, p_{N_i}^{(i)}\} \subset \mathbb{R}^3$。

\subsection{数据预处理：归一化与维度加权}

原始坐标需通过归一化映射到可比的几何空间。系统提供两种归一化方法：(1) \textbf{Min-Max（默认）}：时间轴每条曲线独立归一化至 $[0,1]$，音高与力度除以 127，所有曲线映射至单位立方体 $[0,1]^3$；(2) \textbf{Z-Score（可选）}：所有维度做零均值单位方差标准化，消除量纲差异。归一化后，可通过对各轴施加权重 $(w_t, w_p, w_v)$ 来调节维度重要性。为保证不同长度乐曲的可比性，所有曲线经 64 点线性重采样统一点数。

\subsection{数据清洗：三道质量防线}

数据集初始设计为五类各 25 首的完全平衡结构（125 首）。为消除数据噪声对建模的影响，建立三道滤除防线：(1) Essen 纯净单轨导出——Essen 民谣数据库以 \texttt{.krn} Humdrum 格式存储，所有曲目录入时严格遵循"单旋律线"原则，无和弦/伴奏声部，通过 \texttt{\_parse\_krn\_to\_curve()} 遍历 \texttt{score.flatten().notes} 提取纯音符序列；(2) 最高音线强制过滤——对于多声部现代曲风，对同一时间戳上的和弦仅保留冠音（$\max(\mathrm{pitch})$），基于音乐学事实：人声旋律位于最高声部；(3) 自动质量审查——剔除时长 $< 30$s、音符数 $< 100$ 及类内极端离群点（距离 $>$ 类内均值 $+ 2\sigma$ 阈值），9 首低质量样本详见附录。最终锁定 116 首样本（Classical 25、Folk 23、Jazz 21、Pop 25、Rock 22）。

\subsection{Hausdorff 距离度量族}

\textbf{定义 1（有向 Hausdorff 距离）}
设 $A, B \subset \mathbb{R}^D$ 为两个有限点集，从 $A$ 到 $B$ 的有向 Hausdorff 距离为：
\begin{equation}
    \vec{H}(A, B) = \max_{a \in A}\; \min_{b \in B}\; \|a - b\|_2
    \label{eq:directed}
\end{equation}

\textbf{定义 2（标准双向 Hausdorff 距离）}
\begin{equation}
    H_{\text{std}}(A, B) = \max\Bigl(\vec{H}(A, B),\; \vec{H}(B, A)\Bigr)
    \label{eq:standard}
\end{equation}

\textbf{定义 3（Modified Hausdorff 距离，MHD）}
本模型的核心度量，以平均最近邻距离替代最大值，提升对离群音符的鲁棒性：
\begin{equation}
    H_{\text{mod}}(A, B) = \max\Bigl(\frac{1}{|A|}\sum_{a \in A} \min_{b \in B} \|a - b\|_2,\; \frac{1}{|B|}\sum_{b \in B} \min_{a \in A} \|b - a\|_2\Bigr)
    \label{eq:modified}
\end{equation}

MHD 以均值替代最大值：标准 Hausdorff 的 $L_\infty$ 范数使单个离群音符主导整体距离；MHD 将聚合范数降至 $L_1$（平均意义上），使度量对装饰音、力度波动等局部扰动具有统计稳定性。实现时采用 \texttt{scipy.spatial.KDTree} 加速最近邻搜索，将复杂度从 $O(NM)$ 降至 $O((N+M)\log(\min(N,M)))$。

\textbf{定义 4（离散 Fr\'{e}chet 距离）} 保持点序约束，通过 $O(NM)$ 动态规划求解。
\textbf{定义 5（归一化 DTW 距离）} 通过非线性时间对齐求累积距离最小化。

\subsection{距离矩阵构建与增量扩展}

对 $N$ 条旋律曲线，定义距离矩阵 $D \in \mathbb{R}^{N \times N}$ 满足 $D_{ij} = H_{\text{mod}}(C_i, C_j)$。矩阵具有对称性 $D_{ij} = D_{ji}$ 和零对角线 $D_{ii} = 0$。系统通过 \texttt{DISTANCE\_FUNCTIONS} 策略模式字典支持四种距离方法的动态切换。为支持多批次文件导入场景，实现增量扩展机制：当新增曲线时，仅计算 $O(N_{\text{new}} \times N_{\text{all}})$ 对距离，避免全量 $O(N^2)$ 重算。

\subsection{降维、聚类与分类模型}

在获得距离矩阵后，构建以下分析模型：

\begin{enumerate}[label=(\arabic*),leftmargin=2em]
    \item \textbf{Classical MDS 降维}。双中心化 $B = -\frac{1}{2}JD^{(2)}J$，其中 $J = I - \frac{1}{N}\mathbf{1}\mathbf{1}^T$，$D^{(2)}$ 为距离平方矩阵。对 $B$ 做特征分解 $B = V\Lambda V^T$，取前两个最大特征值对应的特征向量 $V_2\Lambda_2^{1/2}$ 作为二维嵌入坐标。手动实现，便于理解算法原理。系统同时提供 t-SNE 降维作为备选（降级回退至 MDS）。
    \item \textbf{凝聚层次聚类}。基于 SciPy \texttt{linkage(method="ward")} + \texttt{fcluster}，输出树状图。
    \item \textbf{留一法 KNN 分类器}。对每个样本，寻找除自身外距离最近的 $K$ 个邻居，以多数投票确定预测标签，平局时取累积距离最小的标签。输出 accuracy、macro\_precision、macro\_recall、macro\_f1、weighted\_f1 及混淆矩阵。
\end{enumerate}

\subsection{模型求解方法}

上述模型的数值求解通过 Python 实现：music21 库解析 MIDI 文件提取音符序列；\texttt{scipy.spatial.KDTree} 加速 MHD 最近邻搜索，将复杂度从 $O(NM)$ 降至 $O((N+M)\log(\min(N,M)))$；scikit-learn 提供 MDS 降维与层次聚类支持；系统实现了四种距离度量的动态切换与距离矩阵的增量扩展。音频文件（MP3/WAV）可通过预训练的 basic\_pitch 神经网络（ICASSP 2022）转录为 MIDI 后纳入分析流程。完整的工程架构、功能模块与运行说明见附带文档 \texttt{system-guide.md}。

\subsection{类内一致性预检验}

在变换验证之前，先以 v1.1 数据集中 Classical 类别的 25 首样本为对象，检验四种距离方法在\textbf{同一类别内部}的稳定性和致密性——类内距离越小、标准差越小，说明方法对同曲风旋律的一致性刻画越好。

\subsection{距离度量的变换不变性验证}

为检验 Hausdorff 距离族在旋律相似性度量中的几何合理性，依据 Kelly (2012) 提出的变换验证框架，对同一条旋律施加三类音乐变换，验证变换前后的距离应显著小于两条无关旋律之间的距离。

\textbf{移调变换}：对旋律施加 $-12 \sim +12$ 半音的均匀移调。在 Min-Max 归一化下，音高维度的平移导致距离增加；Modified Hausdorff 和标准 Hausdorff 对平移变换最为敏感，Fréchet 和 DTW 因保序匹配对全局平移的敏感性较低。

\textbf{速度缩放}：施加 $0.25\times \sim 4.0\times$ 的等比例速度缩放。Min-Max 归一化将各曲线时间轴独立压缩至 $[0,1]$，等比例线性时间缩放被归一化完全抵消——所有缩放因子下距离均为 0，验证了当前归一化策略的天然速度不变性。

\textbf{节奏扰动}：施加不同强度的高斯时间噪声（$\sigma = 0.01 \sim 1.0$\,s）。距离随噪声强度单调递增，验证了度量的合理性。DTW 对微小节奏扰动敏感度最低（弹性对齐特性），Modified Hausdorff 最敏感——翻唱通常伴随节奏变化，高灵敏度对翻唱检测是优势。

\textbf{正负样本分离检验}：生成 30 对正样本（随机曲线及其 $+3$ 半音移调版本）与 30 对负样本（两条随机不同曲线），对比四种距离方法的分离能力。

\subsection{问题二：三维度中哪个贡献最大？}

\textbf{音高（pitch）贡献最大，力度（velocity）贡献最弱。}

\begin{enumerate}[label=(\arabic*),leftmargin=2em]
    \item \textbf{音高是最强区分维度}。Classical $\leftrightarrow$ Jazz 是主要混淆方向，两类类间 MHD 距离 0.100 略低于 Classical 类内距离 0.101，这一反常现象直接源于音高维度的几何重叠（肖邦半音化和声与 Bebop 半音趋近高度相似）。
    \item \textbf{力度贡献最弱}。MIDI 力度标注一致性极低，Essen 数据库不含力度信息（统一赋 80），力度信噪比远低于其他维度。
    \item \textbf{时间维度节奏信息已被 Min-Max 压缩}。Rock 与 Pop 类间距离仅 0.115，仅凭 $(t, m, v)$ 难以分解 Pop-Rock 连续体。
\end{enumerate}

\subsection{模型优点}

\begin{enumerate}[label=(\arabic*),leftmargin=2em]
    \item \textbf{几何直观性强}。将音乐旋律映射为三维空间曲线，使抽象的相似性问题转化为直观的几何距离问题，模型原理易于理解和解释。
    \item \textbf{对声学噪声具备天然免疫力}。直接基于符号化乐谱（MIDI、Humdrum）建模，彻底剥离伴奏混响、音色等声学干扰，从根本上解决了传统 MFCC 等方法的高噪声问题。
    \item \textbf{MHD 的鲁棒性优势显著}。通过均值聚合替代最大值聚合，MHD 对装饰音、力度波动等 MIDI 数据中常见的局部扰动具有统计稳健性。变换验证实验确认其在综合评分中排名第一，分离比（2.23 vs 1.54）较标准 Hausdorff 提升 44.8\%。
    \item \textbf{模型可扩展性强}。距离矩阵框架天然支持多种距离度量（已集成 4 种）的即插即用，增量扩展机制使模型可持续纳入新数据而无需全量重算。
    \item \textbf{多数据集验证收敛}。在 v1.1 自建集（79.3\%）、Essen 民歌集（81.1\%）和 GTZAN 音频转录集（43.7\%）三个形态迥异的数据集上，MHD 的一致优势证明了方法的泛化能力。
\end{enumerate}

\subsection{模型局限}

\begin{enumerate}[label=(\arabic*),leftmargin=2em]
    \item \textbf{Pop/Rock 区分力不足}。当前 $(t, m, v)$ 三元组在区分 Pop 与 Rock 时表现不佳（Rock 召回率仅 31.8\%，类间距离 0.115）。两类共享主歌-副歌结构、I-V-vi-IV 和弦进行和相似音域，三维几何特征不足以捕捉其本体论差异。
    \item \textbf{Classical/Jazz 存在严重混淆}。两类的类间距离（0.100）甚至略低于 Classical 类内距离（0.101），肖邦半音化和声与 Bebop 半音趋近在音高轨迹上的几何相似性导致两类几乎不可分离。
    \item \textbf{力度维度信噪比低}。MIDI 文件中力度标注一致性极低（不同编曲者差异巨大，Essen 数据库不含力度信息），使得力度维度的有效信息量远低于音高维度。
    \item \textbf{音频转录的输入质量差异}。GTZAN 实验中不同流派的音符密度差异巨大：classical 平均 156 个音符/首，hiphop 仅 42 个（差距 3.7$\times$）。低密度转录曲线可用的几何信息有限，直接导致 hiphop（召回率 16.7\%）和 country（召回率 16.7\%）的分类效果最差——这不是旋律几何方法的边界，而是转录输入质量的结构性差异，说明音频转录管线的性能对下游分类存在瓶颈效应。
    \item \textbf{Min-Max 归一化压缩了绝对节奏信息}。每条乐曲时间轴独立归一化至 $[0,1]$ 虽保证了长度不同的乐曲可比，但也消除了绝对节奏密度信息，一定程度上削弱了节奏型对曲风的区分能力。
    \item \textbf{音频转录引入级联误差}。GTZAN 实验中，basic\_pitch 转录准确率并非 100\%，转录噪声经几何距离传播后可能扩大类内方差，降低分离比。
\end{enumerate}

\subsection{模型改进方向}

\begin{enumerate}[label=(\arabic*),leftmargin=2em]
    \item \textbf{高阶特征工程}。引入局部曲率（旋律线的二阶离散差分）、节奏密度（相邻音符时间间隔的熵）、音程跳变分布（大三度/纯五度/八度的频率直方图）作为加权维度，扩充特征空间的判别能力，针对性解决 Rock/Pop 混淆问题。
    \item \textbf{DTW 增强几何不变性}。利用全局 DTW 的对齐路径作为时间伸缩变换函数，将两首旋律在时间轴上非线性对齐后再计算 Hausdorff 距离，提升对自由节奏（Rubato）和装饰音变奏的鲁棒性。
    \item \textbf{图神经网络作曲风嵌入}。将旋律曲线点集建模为 $k$-NN 图，通过 GNN 消息传递学习曲风嵌入，天然兼容可变长度的点集输入，省去均匀重采样的插值误差。
    \item \textbf{跨数据集的泛化验证}。未来计划引入 Lakh MIDI Dataset（17 万首）和 MAESTRO 钢琴演奏数据集进行大规模跨域泛化评估。
    \item \textbf{和弦与和声特征的融入}。拓展模型以考虑多声部信息（而非仅提取最高音线），引入和弦类型分布、和声进行模板匹配等高阶音乐学特征。
\end{enumerate}

\section{MHD 距离计算核心代码}

\begin{lstlisting}[language=python, caption={hausdorff\_modified 核心实现}]
def hausdorff_modified(a_points, b_points):
    """Return modified Hausdorff using mean nearest-neighbor distance."""
    a_points = _validate_points(a_points, "a_points")
    b_points = _validate_points(b_points, "b_points")

    b_tree = KDTree(b_points)
    distances_ab, _ = b_tree.query(a_points)

    a_tree = KDTree(a_points)
    distances_ba, _ = a_tree.query(b_points)

    return float(max(np.mean(distances_ab), np.mean(distances_ba)))
\end{lstlisting}

本系统将前述数学模型封装为交互式桌面分析工具。系统的一大创新在于支持 \textbf{MP3/WAV 音频直接导入}：通过集成 Spotify basic\_pitch 神经网络模型（ICASSP 2022），用户可将任意音频文件拖入系统，自动转录为 MIDI 符号序列后纳入完整分析管线，无需预先准备 MIDI 格式数据。以下通过界面截图简要展示其核心功能。

\subsection{三维旋律曲线叠加视图}

系统中央为基于 OpenGL 的三维渲染视图，将多首乐曲的旋律线同时叠加显示。x 轴为归一化时间，y 轴为音高，z 轴为力度，每条曲线以不同颜色标识。用户可旋转、缩放、平移视角，直观比较不同曲风旋律在几何空间中的形态差异——例如 Folk 曲线通常短而平直，Classical 曲线音高跨度大、起伏丰富。
