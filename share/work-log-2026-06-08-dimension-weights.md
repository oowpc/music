# 工作日志：维度权重 UI

**日期**: 2026-06-08

## 背景

时间、音高、力度三个维度对旋律相似性的贡献并不一定相同。实际分析中，音高轮廓通常比力度更重要；某些任务则可能希望强调节奏或弱化力度。因此需要在 UI 中提供可调参数比例。

## 本次改动

1. 新增 `src/processing/weights.py`。
   - `apply_dimension_weights(curves, weights)` 将归一化后的 `(time, pitch, velocity)` 点乘以三个权重。
   - 权重必须为 3 个非负值。

2. 更新 `src/ui/control_bar.py`。
   - 增加时间、音高、力度三个 `QDoubleSpinBox`。
   - 默认权重为 `1.0 / 1.0 / 1.0`，保持旧行为。
   - 范围为 `0.0` 到 `5.0`。

3. 更新 `src/ui/main_window.py`。
   - 每次归一化后应用当前维度权重。
   - 权重变化会重新应用曲线点并让旧距离矩阵失效。
   - 增量矩阵扩展会检查权重是否一致，不会跨权重复用旧矩阵。
   - 片段比较也使用加权后的点。

4. 补充测试。
   - 权重乘法正确性。
   - 非法权重校验。
   - UI 调整音高权重后矩阵失效，重新计算后距离变化。

## 使用说明

默认值：

```text
时间: 1.0
音高: 1.0
力度: 1.0
```

示例：

```text
时间: 0.7
音高: 2.0
力度: 0.4
```

这个配置会提高音高轮廓的影响，弱化力度和时间位置的影响。
